Keterangan: 1 = Benar, 0 = Salah. P = IPK minimal 3,50; Q = tidak menerima beasiswa lain; R = pemenang kompetisi nasional.

Bagaimana sistem menentukan hasil?

  1. Sistem memeriksa apakah IPK mahasiswa minimal 3,50 untuk menentukan nilai P.
  2. Sistem memeriksa apakah mahasiswa tidak menerima beasiswa lain untuk menentukan nilai Q.
  3. Sistem memeriksa status pemenang kompetisi nasional untuk menentukan nilai R.
  4. Sistem menghitung F = (P AND Q) OR R. Jika F = 1, hasilnya Layak. Jika F = 0, hasilnya Tidak Layak.

Catatan: Kriteria ini merupakan aturan simulasi untuk keperluan project Matematika Diskrit, bukan ketentuan resmi dari penyelenggara beasiswa tertentu.
